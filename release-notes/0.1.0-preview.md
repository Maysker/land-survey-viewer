## What's in this preview

- Open DWG (AutoCAD 2000 to 2018+), DXF and TXT/CSV point files; DWG is converted locally.
- Map View with layers, contours and optional official Belgian aerial imagery (Flanders, Wallonia, Brussels).
- 3D Site View with the existing terrain surface, overlays, approximate building volume and optional orthophoto drape.
- Inspect elements and copy or export coordinates at full source precision.
- Plan Mode with area and volume summaries.
- Native Windows window, per-user installer without admin rights, Dark and Light themes.
- Fully local: no analytics, no uploads; imagery only after consent.

## Known limitations

- **Made for one workflow.** This preview was developed for a specific user's survey deliverables and tested on a small set of real files. It is not a universal DWG/DXF viewer; drawings from other surveyors or software may open only partly, or not at all.
- **Not code-signed yet.** Windows SmartScreen may warn on first run: *More info → Run anyway* after verifying the checksum.
- Only Belgian Lambert 72 (EPSG:31370) is placed on the map; other systems open as a local plan.
- Civil 3D objects, proxies, solids, meshes, dimensions, images and paper space are not read.
- Seams between regional imagery services can be visible at region borders.
- The Wallonia imagery service occasionally fails to deliver a tile; the app retries.

## Requirements

Windows 10 or 11 (64-bit), Microsoft Edge WebView2 Runtime (installed by the setup if missing), .NET Framework 4.8.
